MUNDO DIGITAL — SITIO LISTO PARA PUBLICAR GRATIS

Archivos:
- index.html: página principal
- assets/video-1.mp4 y video-2.mp4: videos del sitio

PUBLICAR GRATIS EN NETLIFY DROP:
1. Entra a https://app.netlify.com/drop
2. Arrastra la carpeta completa "mundo-digital-gratis" o el ZIP.
3. Netlify publicará el sitio con un subdominio gratuito .netlify.app.
4. Desde Site configuration > Change site name puedes intentar un nombre como mundodigitalperu.

IMPORTANTE:
- El subdominio .netlify.app puede ser gratis.
- Un dominio propio .com/.pe normalmente se paga.
- Conserva la carpeta assets junto al index.html.
